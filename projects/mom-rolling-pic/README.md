# QA Bi-Daily

Google Apps Script automation for recurring QA standups across multiple projects.

## Capabilities

- Dynamic project configuration
- Separate teams and schedules per project
- Standup sheet generation
- WhatsApp reminders and summaries through Fonnte
- One scalable scheduler for all projects
